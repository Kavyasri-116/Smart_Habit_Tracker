# Smart Habit Tracker

A modern browser-based habit tracking project.

## Features
- Add and categorize daily habits
- Mark habits complete
- Calculate daily completion percentage
- Reset daily progress
- Save data with LocalStorage
- Responsive design

## Technologies
HTML5, CSS3, JavaScript, LocalStorage

## Run in VS Code
Open the folder in VS Code, open `index.html`, then right-click and choose **Open with Live Server**.
